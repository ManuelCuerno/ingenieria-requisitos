# Visor y programas de la lanzadera

Los archivos Python de esta carpeta crean, validan, muestran, aprueban y actualizan
workspaces. `plantilla.html` es la página local de solo lectura.

`ejemplo.json`, `spec.md` y `encargo.md` son una muestra coherente para abrir el visor
y entender el resultado sin crear un proyecto. No son datos de un cliente ni forman
parte de un workspace generado.

Para la guía de uso empieza en el [`README.md` de la raíz](../README.md) o abre el
[`manual completo`](../manual-ingenieria-requisitos.html).
