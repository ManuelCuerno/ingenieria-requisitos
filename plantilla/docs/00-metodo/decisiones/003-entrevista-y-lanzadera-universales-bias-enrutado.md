# ADR-003 — Entrevista universal y orientación enrutada

## Decisión vigente

Todos los proyectos pasan por el mismo triaje y la misma entrevista, tanto si nacen
de cero como si parten de código existente. El tipo declarado es uno de `webapp`,
`automatizacion`, `agente` u `otro` y solo decide qué orientación técnica (`bias.md`)
se copia. No cambia el contrato, los planos ni las puertas del método.

El código existente activa la adopción brownfield; no suspende la entrevista. La
persona describe el futuro deseado y el análisis del código documenta el presente.
Ambas cosas se relacionan mediante un mapa de diferencias sin confundirlas.
